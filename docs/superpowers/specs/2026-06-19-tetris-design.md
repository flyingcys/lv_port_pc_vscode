# 俄罗斯方块(Tetris)LVGL 复刻设计

**日期：** 2026-06-19
**分支：** release/v9.5-allinone
**参考：** 仓库根 `ds1.html`
**范围：** 竖屏俄罗斯方块,自适应三档分辨率,接入 all-in-one 桌面

---

## 一、目标与朝向

物理屏为横屏,俄罗斯方块为竖向玩法,游戏**按竖屏逻辑分辨率**实现,玩时把设备转成竖屏。

三档自适应逻辑分辨率(竖屏):

| 物理(横) | 逻辑(竖) | 分档 |
|-----------|----------|------|
| 800×480 | 480×800 | 480 宽档 |
| 640×480 | 480×640 | 480 宽档(高 600~800 兼容) |
| 480×272 | 272×480 | 272 宽档 |

布局按**逻辑宽**分两档(480 / 272),棋盘高度按可用高度夹取。

---

## 二、玩法规则(对齐 ds1.html)

- 网格 10 列 × 20 行;7 种方块 I/J/L/O/S/T/Z,颜色值与 ds1.html 一致
- 方块 3D 立体效果(左上高光、右下暗边)+ 浅网格线
- 旋转:矩阵转置(顺时针),撞墙时左/右各试一格(wall kick 简化版),失败则还原
- 计分:`points[linesCleared] × level`,`points=[0,100,300,600,1000]`
- 升级:`level = lines/10 + 1`;下落间隔:`max(100, 1000-(level-1)*100)` ms
- 下一个方块预览;开始/暂停/重新开始;顶到顶部即游戏结束(遮罩 + 最终得分 + 重开)

## 三、渲染

- 棋盘与"下一个"用 `lv_canvas`(RGB565 省内存),仅在状态变化(移动/旋转/锁定/消行)时重绘
- 单格绘制复刻 ds1.html `drawBlock`:填充 + 黑描边 + 左上 `rgba(255,255,255,0.2)` 高光 + 右下 `rgba(0,0,0,0.2)` 暗边
- 网格线:`rgba(255,255,255,0.1)`
- 背景沿用 ds1.html 渐变氛围(深色容器,棋盘 `#111`,棋盘边框 `#3498db`)

## 四、布局

**480 宽档(480×800 / 480×640):**
- 顶部:标题"俄罗斯方块" + 得分/等级/已消除行
- 中部:棋盘 canvas(块 ~26px,棋盘 260×520),居中
- 棋盘右上/下方:下一个预览
- 底部:触摸按钮 ◀ ▶ ⟳(旋转) ▼(软降) ⤓(直落) + 开始/暂停/重开

**272 宽档(272×480):**
- 省略大标题,得分用紧凑单行
- 棋盘块 ~13px(棋盘 130×260),下一个缩小
- 按钮行紧凑

## 五、操作

- **触摸按钮**(竖屏触摸屏主用):左移/右移/旋转/软降/直落 + 开始/暂停/重开
- **键盘**(模拟器调试):←→ 移动,↑ 旋转,↓ 软降,空格 暂停

## 六、线程与生命周期

- 单 `lv_timer`(主线程)驱动下落与重绘,不新增线程(无跨线程问题)
- `tetris_set_active(bool)`:离开/返回桌面时暂停/恢复(对齐 fruit_ninja 模式)

## 七、集成(渐进式)

1. 先做**独立竖屏 app**:`main` 以竖屏尺寸运行可直接验证(模拟器 `./bin/main 480 800`)
2. 再**接入桌面图标**"俄罗斯方块":点击时 `lv_display_set_rotation(LV_DISPLAY_ROTATION_90)` 切竖屏进入,返回桌面时恢复 `ROTATION_0`;懒构建 + 持久化(同 music/fruit 模式)
   - 若该 LVGL 构建的显示旋转不可用,则退化为独立 app(仍按竖屏尺寸,设备物理旋转)

## 八、文件与构建

```
main/src/v9-tetris/
  tetris.h            ← 公开 API:tetris_start / tetris_set_active
  tetris.c            ← 游戏逻辑 + canvas 渲染 + 触摸/键盘输入
  tetris_font_*.c     ← 中文标签子集字体(SourceHanSansSC,非压缩,lv_font_conv 生成)
```
- CMake:`main/src/v9-tetris/*.c` 以 GLOB 或显式加入 `main` target(与 fruit_ninja 一致)
- 桌面:`desktop.c` 新增"俄罗斯方块"图标 → `tetris_start` + 旋转切换

## 九、测试与验证

- 纯逻辑单测(无 LVGL):碰撞 `is_collision`、旋转 `rotate`、消行 `check_lines`、计分 `update_score`——对齐 ds1.html 行为(参照 fruit_ninja 单测模式,加 CMake test target)
- 无头截图:480×800 / 272×480 两档布局;落子/消行/游戏结束;桌面进入→游玩→返回
