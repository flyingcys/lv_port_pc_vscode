# MasterGo Scenes 页面 LVGL 还原设计文档

## 背景

当前仓库是 `LVGL PC Simulator` 工程，仓库里已有一版旧的首页页面实现，但用户这次给出的 MasterGo 链接对应的是另一套 `480 x 480` 的智能家居场景页，需要以该设计为准重新实现，并替换当前首页入口。

本次以 MasterGo 设计链接和对应 DSL 为唯一验收基准，而不是以现有实现为准。目标设计节点为：

- 文件：`131850344368735`
- 图层：`sa281:4872`
- 节点名称：`首页`
- 页面视觉标题：`Scenes`
- 设计画布：`480 x 480`

## 目标

- 在当前 LVGL v9 工程内实现新的 `Scenes` 页面
- 替换当前首页入口，启动后直接显示该页面
- 以 `LVGL` 原生对象、原生样式和绝对坐标为主完成还原
- 仅在图标等必要位置使用本地化资源，不把页面整体做成截图
- 支持当前页内卡片选中态切换，但暂不实现“下一个动作”或页面跳转

## 设计范围

### 包含内容

- 深色固定尺寸页面根容器
- 顶部天气、温度、Wi-Fi、AM/日期/时间信息栏
- 标题区 `Scenes` / `Devices`
- 四张场景卡片
- 底部渐变遮罩
- 底部分页指示器
- 当前页内卡片点击反馈与选中态切换

### 不包含内容

- 真实设备控制
- 网络请求
- 实时时钟和实时天气
- 原型中的下一个动作、页面跳转或业务联动
- 与本页面无关的重构

## 已确认约束

### 设计与实现基准

- 最终以 MasterGo DSL 为准
- 固定尺寸页面严格按绝对坐标落地，不做响应式推导
- 优先使用 `LVGL` 原生实现，不使用整页大图代替页面
- 截图只用于调试和验收，不作为设计数据来源

### 交互边界

- 四张卡片只做当前页内选中态切换
- `Scenes` / `Devices` 只保留视觉状态，不触发下一页
- 分页指示器只反映状态，不单独触发动作
- 本轮不实现任何“下一个动作”

### 命名约束

本轮页面模块统一改名为：

- `scenes_page.c/.h`
- `scenes_assets.c/.h`

不继续沿用当前的 `home_page` / `home_assets` 命名。

  - 顶部信息栏文字与图标布局

## 页面结构设计

### `scenes-screen-root`

根容器负责：

- 固定 `480 x 480` 画布
- 页面底色
- 承载所有视觉层
- 禁用滚动和无关样式

### `top-info-bar`

顶部信息栏负责：

- 左侧天气图标与温度
- 右侧 Wi-Fi 图标
- `AM`、日期与时间
- 保持 `x=16, y=15, w=448, h=32`

### `tab-title-block`

标题区负责：

- 激活态标题 `Scenes`
- 非激活态标题 `Devices`
- 保持设计稿中的大小、透明度和相对间距

### `scene-card-grid`

卡片区负责：

- 左上 `Home`
- 左下 `Leaving Home`
- 右上 `Morning`
- 右下 `All Lights On`

四张卡片统一使用同一套卡片组件结构，差异通过状态和配置表达，不为每张卡片复制不同实现。

### `bottom-fade`

底部遮罩负责：

- 提供从透明到黑色的渐变
- 增强底部内容层级感
- 保持底部 `52px` 高度的视觉覆盖

### `pager-block`

分页区负责：

- 一个半透明白色圆点
- 一个青色激活条
- 跟随当前页面状态变化，但不触发新动作

## 视觉与状态策略

### 原生实现优先项

- 页面根容器和坐标布局
- 标题区文本
- 卡片底色、圆角、渐变
- 分页和底部遮罩
- 当前页内选中态切换

### 本地化资源优先项

- 天气图标
- Wi-Fi 图标
- 无法稳定用矢量还原的卡片图标

### 状态收敛策略

右上卡片在 DSL 中出现了两份同位蓝色节点：

- `sa281:4954`，尺寸 `219 x 145`
- `sa281:5394`，尺寸 `219 x 135`

实现时不直接保留两层重叠对象，而是收敛为单一“选中态”卡片样式：

- 初始选中卡片为 `Morning`
- 其他卡片点击后，切换当前选中索引
- 只更新卡片状态，不触发新动作

## 验证标准

### 视觉验证

- 页面整体构图与 MasterGo 设计稿一致
- 顶部信息栏各元素位置正确，没有错位和遮挡
- `Scenes` / `Devices` 的字号、透明度、间距接近设计稿
- 四张卡片的坐标、大小、圆角和标题位置一致
- 右上 `Morning` 卡片初始为选中高亮态
- 点击卡片后，仅发生当前页内选中态切换
- 底部分页和渐变遮罩位置正确

### 工程验证

- 工程可以编译通过
- 页面可在 LVGL 模拟器中运行
- 所有本地资源路径有效
- 新增或修改文件没有明显编译错误

### 调试方式

当前仓库按如下方式调试和验收：

1. 执行构建：`cmake -B build -S . && cmake --build build -j$(nproc)`
2. 运行模拟器：`./bin/main`
3. 通过截图与 MasterGo 页面人工对比
4. 对坐标、尺寸、字体、透明度、渐变和层级做迭代微调

## 已知风险与接受偏差

- `LVGL` 原生渐变方向和毛玻璃效果可能与设计稿存在轻微差异
- 某些图标若无法稳定用原生矢量表达，将改为本地图片
- 如果设计字体在本地加载失败，需要使用最接近字体替代，并在结果汇报中说明偏差
