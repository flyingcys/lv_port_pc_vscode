# MasterGo 首页 LVGL 还原设计文档

## 背景

当前仓库是 `LVGL PC Simulator` 工程，首页已经有一版基于 MasterGo 的初稿实现，但视觉效果和设计稿差距较大。用户明确要求继续使用当前仓库和 `mastergo mcp` 提供的设计数据，把首页做成和设计稿尽量一模一样，并且指出当前效果可参考截图中的问题表现。

本次以 MasterGo 设计链接为唯一验收基准，而不是以当前截图为准。目标设计节点为：

- 文件：`131850344368735`
- 图层：`sa281:8161`
- 页面名称：`首页`
- 设计画布：`480 x 480`

## 目标

- 在当前 LVGL 工程内完成首页静态视觉 1:1 还原
- 继续沿用现有 `main/src/home_page.c` 页面接入方式，而不是新建 HTML 静态页
- 用 MasterGo DSL 中的真实坐标、颜色、字体和资源修正当前页面偏差
- 保持后续可维护性，优先让难以精确还原的视觉层落地为资源

## 设计范围

### 包含内容

- 整页深色背景和氛围图
- 左上天气图标、温度、日期、星期
- 中部静态时钟 `09:26`
- 下方两张开关卡片
- 右上 Wi-Fi 图标
- 底部分页指示器

### 不包含内容

- 多页面跳转
- 实时时钟
- 业务联动
- 开关交互逻辑扩展
- 与设计稿无关的重构

## 已确认约束

### 基准

- 最终以 MasterGo 设计链接为准
- 当前截图只用于说明“现有效果不好”，不作为最终样式标准

### 实现方式

- 基于当前仓库现有 LVGL 页面继续改造
- 允许新增或替换资源，以优先保证视觉一致性
- 采用 `LVGL 布局 + 设计资源混合还原` 方案

### 视觉范围

- 先只做当前首页静态视觉 1:1
- 不要求本轮补做额外交互

### 圆角策略

- 最外层页面容器不使用圆角
- 内部卡片、分页等局部圆角按设计稿保留

## 页面结构设计

本次页面在 LVGL 中保持以下结构拆分：

### `screen-root`

根容器负责：

- 固定 `480 x 480` 画布
- 深色底色
- 承载所有视觉层
- 去掉最外层圆角和外层裁切

### `ambient-background`

背景层负责：

- 使用设计稿背景图 `paint_162:5725`
- 保持倾斜氛围图的视觉方向
- 通过附加暗色覆盖层控制前景可读性

### `weather-block`

天气区负责：

- 天气图标
- 温度 `26℃`
- 日期 `6/24`
- 星期 `周一`

### `clock-block`

时钟区负责：

- 四位数字
- 中间红色双点冒号
- 大字号 Urbanist 数字排版

### `switch-card-left`

左卡负责：

- 深色半透明材质底
- 底部浅色指示条
- 文案 `开关一`

### `switch-card-right`

右卡负责：

- 浅色渐变卡片底
- 青色指示条
- 文案 `开关二`

### `wifi-block`

右上 Wi-Fi 图标区域。

### `pager-block`

底部分页条和圆点区域。

- 时钟模块：`x=28, y=113, w=278, h=132`

- 右卡片：`x=248, y=298, w=204, h=140`

本次实现应直接以这些数据为基准，不再靠手调近似。

## 视觉还原策略

### 继续使用 LVGL 的部分

- 页面层级和对象树
- 位置、尺寸、圆角、透明度等基础布局属性
- 字体加载与文本绘制
- 简单的纯色、渐变和基础阴影

### 改为资源优先的部分

- 背景氛围图
- 天气图标
- 红色双点冒号
- 若 LVGL 难以精确复现的卡片材质或装饰层

### 设计 token

实现中需要尽量对应以下 DSL token：

- 页面底色：`paint_161:3344 = #070709`
- 左卡背景：`paint_162:3498 = rgba(0,0,0,0.8) + rgba(255,255,255,0.15)`
- 右卡背景：`paint_161:3037 = linear-gradient(123deg, #F5F9FD -1%, #C3D2E1 98%)`
- 左卡条：`paint_3:01258 = rgba(255,255,255,0.2)`
- 右卡条：`paint_3:01309 = #0BCAD0`
- 左卡文字：`paint_3:8068 = rgba(255,255,255,0.9)`
- 右卡文字：`paint_161:3055 = rgba(0,0,0,0.9)`
- 天气温度：`font_162:5711 = Urbanist 32 Bold`
- 日期星期：`font_162:5662 = Source Han Sans CN 20 Medium`
- 时钟：`font_162:00423 = Urbanist 110 Bold`
- 卡片标题：`font_162:3518 = Source Han Sans CN 22 Bold`
