# desktop 学习文档

> LVGL v9 实现的"桌面壳层"：壁纸 + 状态栏 + 锁屏页 + 两页 app 网格 + 控制中心 / 通知中心 + 边缘手势 + 应用启动器。共 35 个文件、约 2700 行，挂在 `lv_screen_active()` 上，是所有 app 的统一入口。

## 1. 整体架构

```
                          lv_screen_active()
                                  │
        ┌──────────────┬──────────┼──────────┬────────────────────────┐
        │              │          │          │                        │
   wallpaper        top_bar    desktop_home  pager_dots     edge_top / edge_bot
   (lv_image)      (root+3 slot) (tileview)  (dots row)     (透明感应条)
                       │           │
                ┌──────┴──┐    ┌───┴────┬────────┬────────┐
                │left  │right│  page_0  page_1   page_2
                │clock │icons│  锁屏   10 app    2 app
                └──────┴─────┘  时钟    瓷砖×10   瓷砖×2
                                                  │
                                       desktop_widget_app_tile
                                          (lv_obj+image+label)
                                                  │
                                       pressed/released/touching
                                                  ↓
                                       desktop_apps[idx].launch()
                                                  ↓
                              desktop_app_launcher_open_with_close
                                          (黑色 overlay)
                                                  │
                            ┌────────────┬────────┼────────┬───────────┐
                       apple_music   fruit_ninja  tetris  game_2048  ...
                                                                 (各自 builder)

   控制中心 (从顶部下滑)        通知中心 (从底部上滑)
   desktop_panels.control       desktop_panels.notify
   (glass_panel + toggle ×4     (glass_panel + 通知卡片 ×N)
    + slider ×2 + handle)
```

模块边界一句话总结：

- `desktop.c` —— 系统层"主进程"，组合所有子模块、管理桌面运行时状态（拖拽/抖动/分页/边缘条）。
- `desktop_home.c` —— 桌面的 `tileview` 容器，负责 3 页的滑动和当前页回调。
- `desktop_top_bar.c` —— 状态栏。
- `desktop_panels.c` —— 控制中心 + 通知中心两块面板。
- `desktop_app_launcher.c` —— 全局应用 overlay 接口，所有 `*_app.c` 都通过它。
- `*_app.c` —— 桌面与具体应用的薄胶水层（builder + 返回键 + 资源清理）。
- `desktop_data.c` —— 桌面元数据：app 列表、通知列表。
- `desktop_metrics.c / desktop_theme.c` —— 分辨率档位 + 配色。

## 2. 文件分层表

| 文件 | 用途 / 对外暴露 |
|------|----------------|
| `desktop.h` | 仅一个 `desktop_run(void)` |
| `desktop.c` | 桌面主入口；建壁纸/锁屏/瓷砖/状态栏/分页点/面板/边缘条；处理图标按下-长按抖动-拖拽-跨页搬运-短按启动 |
| `desktop_layout.h` | 不依赖 lvgl 的常量：`DESKTOP_PAGE_COUNT=3`、`DESKTOP_GRID_COLS=5`、`DESKTOP_GRID_ROWS=2`、`DESKTOP_SLOT_COUNT=10` |

| `desktop_panels_geom.h/.c` | 面板几何：`reveal → y` 钳制、半开吸附阈值；纯函数，无 lvgl 依赖 |

| `desktop_assets.h / desktop_assets_bundle.c` | 把 LVGL demo 的若干图片打包成 `desktop_assets[]`（供测试/示例使用，不上桌面） |

| `assets/img_app_*.c` | 12 个 app 图标 + 3 张壁纸 + 字体（`fonts/desktop_font_*.c`），全部 LVGL C 数组 |

## 3. 启动流程

PC 入口在 `main/src/main.c`：

```
main()
 ├─ lv_init()
 ├─ resolve_resolution(&w,&h)             // 读 AM_RES，默认 800x480
 ├─ desktop_set_resolution(w,h)           // 锁定 s_res 档位，所有 metrics getter 跟着切换
 ├─ hal_init(w,h)                         // lv_sdl_window_create + 鼠标/键盘 indev + 默认 group
 ├─ maybe_run_calc_standalone(w,h)        // AM_APP=calc_standalone 时直接跑计算器，不进桌面
 ├─ desktop_run()         ──────────────► 见下方调用链
 ├─ if(AM_APP=="xxx") xxx_app_launch()    // 截图钩子
 ├─ maybe_take_snapshot()                 // AM_SHOT 时单帧出图退出
 └─ while(1) lv_timer_handler(); usleep(5ms)
```

FreeRTOS 路径走 `freertos_main()`，其内部任务也会调用 `desktop_run()`，落点一致。

`desktop_run()`（即首屏渲染主调用链）：

```
desktop_run()
 ├─ 复位静态状态（icons[][], page_icon_count[], 拖拽计数...）
 ├─ destroy 现有 top_bar / desktop_home / panels（支持重入）
 ├─ lv_obj_clean(lv_screen_active())              // 清空旧屏
 ├─ desktop_home_create(scr, page_changed_cb)     // tileview + 3 tile
 ├─ 取出 page[0..2]，把 tileview/page 背景置 LV_OPA_TRANSP
 ├─ lv_image_create(壁纸) + lv_obj_move_background  // 最底层
 ├─ for i in desktop_apps[]:                       // 按 .page 字段分发到 page_1/page_2
 │    desktop_widget_app_tile(page[pg], &app[i])
 │    lv_obj_set_size/set_pos
 │    add_event_cb(pressed/released/touching)
 ├─ page[0] 上居中加锁屏大时钟 lv_label_create
 ├─ desktop_top_bar_create(scr)
 │    └─ apply(page_config[0]) + set_wifi_state + start_minute_timer
 ├─ pager_dots = desktop_widget_dots(scr,2,0); 初始隐藏
 ├─ AM_PAGE 环境变量 → lv_tileview_set_tile (截图钩子)
 ├─ desktop_panels_create(scr)
 ├─ AM_PANEL 环境变量 → desktop_panels_apply_initial
 └─ edge_top / edge_bot：scr 子节点最后创建 = 渲染层最顶
       └─ desktop_panels_bring_to_front(panels)   // 再把面板提到边缘条之上
```

关键不变量：

- 壁纸 `lv_obj_move_background`、感应条最后创建、面板再 `move_foreground`。三者顺序定义了"壁纸在最底、感应条只在桌面态接触手指、面板展开后压住感应条"的层级关系。
- `lv_obj_clean(lv_screen_active())` 一次性回收所有子对象；模块自身没有"内存归还"路径，全靠 LVGL 的删除链 + 模块各自挂的 `LV_EVENT_DELETE` 把 C 结构 `lv_free` 掉。

## 5. 状态栏 desktop_top_bar.c

布局：root 是屏宽 × `m->top_bar_h`、`bg_opa=TRANSP` 的 `lv_obj`，里面三个槽：

| 槽 | 宽度 | 对齐 | 控件 | 字体 |
|----|------|------|------|------|
| `left_slot` | `screen_w * 30%` | `LEFT_MID`, +8px | 时钟 `lv_label` | `font_clock` (Montserrat) |
| `center_slot` | `screen_w / 3` | `CENTER` | 保留（默认 HIDDEN） | `font_clock` |
| `system_right_slot` | `screen_w * 45%` | `RIGHT_MID`, -8px | flex row：信号 / WiFi / "100%" / 电池 | `font_glyph` + `font_clock` |

右槽用 `LV_LAYOUT_FLEX` + `LV_FLEX_FLOW_ROW`，`pad_column=4`、`align(END, CENTER, CENTER)`。信号 / WiFi / 电池图标都是 `lv_label`，文字内容来自 `DESKTOP_GLYPH_*` 宏（Phosphor 字体子集里的 UTF-8 码点）。

刷新机制：

- `desktop_top_bar_start_minute_timer()` 创建一个 `lv_timer`。**首次 period 不是 60 s**，而是 `top_bar_get_initial_period_ms()` 计算"到下一整分钟的毫秒数"——这样跨过 :00 之后 `lv_timer_set_period(timer, ...)` 重置为 60 000 ms 长跑，时钟字面跳变与真实分钟边界对齐。
- 回调 `top_bar_minute_timer_cb` 内部用 `time()` + `localtime_r()` + `strftime("%H:%M")` 写 `clock_label`。
- 删除链：`root` 的 `LV_EVENT_DELETE` 回调 `top_bar_delete_cb` 同时 `lv_timer_delete` + `lv_free(top_bar)`，避免 timer 在 owner 销毁后还在跑。

页相关切换走 `desktop_top_bar_apply(top_bar, desktop_get_page_config(page_idx))`：当前实现里 left=时钟常驻、center 始终隐藏、system_right 由 `config->show_system_right` 决定显示与否。`apply` 由 `desktop_home` 的 `page_changed_cb` 在每次 tileview 切页时触发。

## 6. 应用面板 desktop_panels.c / desktop_panels_geom.c

两块面板都通过 `desktop_widget_glass_panel(parent, screen_w, screen_h)` 创建为屏宽 × 屏高的 `lv_obj`（半透明深色 + 1px 白边 + 阴影）。`set_style_radius(p, 0, 0)` 把"全屏铺满"档下的圆角去掉，防止露壁纸。

布局都用 `LV_FLEX_FLOW_COLUMN`：

- 控制中心：标题 → 4 个 toggle（flex row）→ 2 个 slider → spacer(`flex_grow=1`) → 把手。
- 通知中心：把手 → 标题 → 通知卡片循环（`desktop_notifies[]`，每张是 title/body/time 三个 `lv_label`）。

几何与吸附（`desktop_panels_geom.c` 提供，**与 lvgl 解耦，可单测**）：

- `desktop_panel_drag_y(which, reveal, panel_h, screen_h)`：把"从全关起算的露出像素 `reveal`"映射到 `y`。control 全关 `-panel_h`、全开 `0`；notify 全关 `screen_h`、全开 `screen_h-panel_h`。
- `desktop_panel_snap_open(reveal, panel_h, last_delta)`：松手吸附判定。`|last_delta| ≥ DESKTOP_PANEL_FLICK_PX(12)` 按方向兜底；否则按 `reveal ≥ 50%·panel_h`。

动画用 `lv_anim_t` 直跑 `lv_obj_set_y`，开 = `lv_anim_path_overshoot`（带回弹），关 = `lv_anim_path_ease_in`。

收起手势：`attach_drag()` 把 `PRESSED / PRESSING` 直接挂在整块面板上，按下记录 `handle_press_y`，移动方向相反距离 > 50px 就触发 `slide_to(closed)`。`which_of_panel()` 沿父链回溯把"装饰子对象"的按压归并到所属面板——这样用户即便戳到 slider 周边空白也能拉回去。

由 `desktop.c` 的边缘条触发打开：

- `edge_top` 按下后跟手下滑 > 50px → `desktop_panels_show_control(true)`。
- `edge_bot` 按下后跟手上滑 > 50px → `desktop_panels_show_notify(true)`。
- 任一面板已 `active` 时边缘条直接 return，避免重复触发。

## 7. 桌面网格与卡片面板

不是 `lv_btnmatrix`——每个 app 是一个 `lv_obj` 容器（flex column，pad_row=6），里面套一个 `lv_image`（图标）+ `lv_label`（中文名）。详见 `desktop_widget_app_tile()`：

- 图标 C 数组按 **800×480 档** 的 96 px 出图；其它档由 `lv_image_set_scale(img, 256 * m->icon_size / 96)` 等比缩放（LVGL 中 256 = 100%）。
- 标签 `set_long_mode(DOTS)` + `width = col_w-8` + 单行行高，防止 CJK 在窄列里被竖排。

栅格策略（`desktop_layout.h` 固定 5×2 = 10 槽，所有档共用）：

| 屏幕 | col_w | row_h | 同时可见 |
|------|-------|-------|---------|
| 800×480 | 160 | (480-40-20)/2 = 210 | 10 |
| 640×480 | 128 | 210 | 10 |
| 480×272 | 96  | (272-28-14)/2 = 115 | 10 |

`desktop_grid_col_w/row_h` 是单一事实源，所有放置坐标（`x_by_index/y_by_index`）都用它算，不在外面 hardcode。

事件链（瓷砖三事件齐挂）：

```
LV_EVENT_PRESSED   ─→ pressed_cb    记录起点 icon_press_x/y, did_drag=0
LV_EVENT_PRESSING  ─→ touching_cb   判定拖拽 + 长按 70 帧进入抖动模式
                                    抖动模式下跟手移动 + 越界自动翻页
LV_EVENT_RELEASED  ─→ released_cb   分支：
                                     ├ 抖动且同页：本页 reorder + 动画补位
                                     ├ 抖动且跨页：抢占目标页槽或交换
                                     └ 短按 (!did_drag && !icon_shake)：
                                         desktop_apps[meta->app_idx].launch()
```

`meta->app_idx` 是关键——保存到瓷砖的 user_data 里，瓷砖搬家时跟着一起迁移；启动时直接拿全局索引，而不是按 (page, slot) 反查（重排后会错位）。

## 8. 启动器协议 desktop_app_launcher

只有三个 API：

```c
lv_obj_t * desktop_app_launcher_open_with_close(
    lv_obj_t * (*builder)(lv_obj_t * overlay, int32_t w, int32_t h),
    void       (*close_cb)(void),
    int32_t w, int32_t h);
void       desktop_app_launcher_close(void);
bool       desktop_app_launcher_is_open(void);
```

内部维护一个**进程级单例** `s_overlay`：

1. 已打开则直接返回，禁止双开。
2. 保存当前 screen 的 `SCROLLABLE` flag 与 scrollbar_mode，并临时关掉，避免 app 内部滚动行为被桌面 tileview 抢走。
3. 在 `lv_screen_active()` 上建一个全屏黑色半透明（opa=160）`lv_obj` 作为 overlay，置 `CLICKABLE`、`move_foreground`。
4. 调 `builder(overlay, w, h)` 由 app 自己在 overlay 上挂 UI。
5. `_close()` 反向：先调 `close_cb`（让 app 释放定时器/解码器等运行时资源），再 `lv_obj_delete(overlay)`，恢复 screen 的 scroll 配置。

每个 `*_app.c` 共性（看 4 份完全一致）：

```c
static lv_obj_t * xxx_builder(lv_obj_t * overlay, int32_t w, int32_t h) {
    lv_obj_t * app = xxx_create(overlay, w, h);   // 调具体 app 模块
    create_back_button(overlay);                  // 圆形返回键，点击 → desktop_app_launcher_close()
    /* 可选：xxx_start() / 资源初始化 */
    return app;
}
void xxx_app_launch(void) {
    const desktop_metrics_t * m = desktop_metrics();
    desktop_app_launcher_open_with_close(xxx_builder, xxx_app_close, m->screen_w, m->screen_h);
}
void xxx_app_close(void) { xxx_stop(); /* 或 deinit */ }
```

返回键统一是：`lv_button_create(overlay)` 44~48 px 圆角 + 圆形白底半透明 + `lv_label` 写 `LV_SYMBOL_LEFT`，左上角偏移 12/12 或 16/56，`lv_obj_move_foreground` 保证盖住 app 自己的内容。

## 9. 手势 desktop_gesture.c

只有两个纯函数 + 两个阈值常量，**没有 indev 监听**——它的作用是给 `desktop.c` 的事件回调提供一致的判定：

- `DESKTOP_GESTURE_TAP_CANCEL_PX = 8`：按下与当前点 |dx| 或 |dy| 超过 8 就视为拖拽，置 `did_drag=1`，松手不再启动 app。
- `DESKTOP_GESTURE_AXIS_PX = 20`：`is_vertical(dx, dy)`，垂直分量大于水平分量且大于 20，用于扩展场景判定竖滑（当前主路径未直接消费，但被边缘条/面板逻辑借鉴）。

边缘条没有走 LVGL 的 `LV_EVENT_GESTURE`，而是手挂 `PRESSED + PRESSING + RELEASED` 自己算位移，因为 LVGL 的 gesture 只在 release 时一次性派发，不适合"跟手"。

## 10. 主题 desktop_theme.c + 分辨率 desktop_metrics.c

`desktop_theme_t` 是一个常量结构体（accent=#007AFF, text_primary=#FFFFFF, panel_bg=#141928@0.75, glass_border=#FFFFFF@0.1, glass_hi=#FFFFFF@0.25, overlay_dark=#000000@0.4）。所有控件创建时直接 `lv_obj_set_style_*(obj, desktop_theme()->xxx, 0)`，**不走 LVGL 主题系统**——主题切换粒度细到每个 part，简单可控。

`desktop_metrics_t` 三档（在 `desktop_metrics.c::s_metrics[]`）：

| 字段 | 800×480 | 640×480 | 480×272 |
|------|---------|---------|---------|
| screen_w / screen_h | 800 / 480 | 640 / 480 | 480 / 272 |
| top_bar_h | 40 | 40 | 28 |
| pager_h | 24 | 24 | 16 |
| icon_size | 96 | 88 | 60 |
| icon_radius | 20 | 20 | 14 |
| panel_h | 408 | 408 | 231 |
| font_label | SimSun 16 | SimSun 16 | SimSun 12 |
| font_clock | Montserrat 18 | Montserrat 18 | Montserrat 14 |
| font_big_clock | Montserrat 48 | Montserrat 48 | Montserrat 40 |
| font_glyph | Phosphor 20 | Phosphor 20 | Phosphor 14 |

`desktop_set_resolution(w,h)` 仅做 `if 800x480 / 640x480 / 480x272` 三选一，索引锁到 `s_res`。之后所有 `desktop_metrics()` 都返回那一档，**不可在运行期热切**——切档需要 destroy + 重新 `desktop_run()`。

## 11. 页面配置 desktop_page_config.c

定义 3 张状态栏页配置（与 `DESKTOP_PAGE_COUNT` 对齐）：

| page | page_mode | left | center | right |
|------|-----------|------|--------|-------|
| 0 锁屏 | `LOCK` | NONE（左槽仍由时钟常驻） | TEXT `09:41`（实测被强制隐藏） | system_right 显示 |
| 1 主页1 | `HOME` | NONE | NONE | system_right 显示 |
| 2 主页2 | `HOME` | NONE | NONE | system_right 显示 |

什么时候用：`desktop.c::desktop_page_changed_cb(page_idx)` 在 `lv_tileview` 切页时被 `desktop_home` 触发，里面调 `desktop_top_bar_apply(top_bar, desktop_get_page_config(page_idx))`，由 `top_bar` 自行根据 `page_mode` / `show_system_right` 调整外观。同时该回调还负责更新 `pager_dots`：锁屏页隐藏，主页页 active=page_idx-1。

`topbar_page_mode_t` 当前在 `top_bar_apply_page_mode()` 里实际只做了"背景始终透明"——保留枚举是为了将来按页换背景/字体色。

## 12. 资源打包：图标、字体、壁纸

所有桌面资源都是 LVGL C 数组，编译进固件：

- `assets/img_app_*.c` —— 12 张 app 图标，每张 96×96 ARGB，约 180 KB/张；通过 `LV_IMAGE_DECLARE(img_app_xxx)` 在 `desktop_data.c` 引用。
- `assets/img_wallpaper_{800x480,640x480,480x272}.c` —— 三档壁纸，`desktop.c::wallpaper_for()` 按当前 metrics 选。
- `assets/fonts/desktop_font_simsun_{12,16}.c`、`desktop_font_phosphor_{14,20}.c` —— 子集字体，`LV_FONT_DECLARE` 在 `desktop_metrics.c` 引用。SimSun 子集只含 app 名 + 面板用到的中文（"控制中心"等），Phosphor 子集只含 `desktop_glyphs.h` 列出的 10 个码点。

`CMakeLists.txt` 第 83~86 行用 `file(GLOB ... main/desktop/{*,calc,assets,assets/fonts}/*.c)` 批量收集；显式追加（252-307 行）保证测试目标也能拿到必要符号。

`desktop_assets_bundle.c` 与上面无关——它把 LVGL 自带 demo 的若干图像组合成 `desktop_assets[]`，用于测试/示例渲染，**桌面本身不引用**。这里列出仅说明文件归属。

`desktop_glyphs.h` 是字形码点宏表（10 个），让代码不用直接写 `"\xee\x85\x82"`，而是 `DESKTOP_GLYPH_SIGNAL`。

## 13. 桌面元数据 desktop_data.c

`desktop_app_t` 只有 4 字段：

```c
typedef struct {
    const lv_image_dsc_t * icon;   // 图标 C 数组的指针
    const char * name;             // UTF-8 显示名
    uint8_t page;                  // 1 或 2（0 留给锁屏）
```

## 14. 接入一个新应用：7 步

以"在 desktop 上挂一个新应用 `foo`"为例，假设 `foo` 自己的 LVGL 应用模块已经在 `main/src/v9_foo/` 写好，提供 `foo_create(parent, w, h)` / `foo_start()` / `foo_stop()`。

**1. 写胶水文件** `main/desktop/foo_app.h`：

```c
void foo_app_launch(void);
void foo_app_close(void);
```

**2. 写 `foo_app.c`**（照搬 `tetris_app.c` 即可）：

```c
static lv_obj_t * foo_builder(lv_obj_t * overlay, int32_t w, int32_t h) {
    lv_obj_t * app = foo_create(overlay, w, h);
    create_back_button(overlay);    // 复用同样的 44×44 圆形返回键代码
    foo_start();
    return app;
}
void foo_app_launch(void) {
    const desktop_metrics_t * m = desktop_metrics();
    desktop_app_launcher_open_with_close(foo_builder, foo_app_close,
                                         m->screen_w, m->screen_h);
}
void foo_app_close(void) { foo_stop(); }
```

**3. 准备图标 C 数组**：用 LVGL Image Converter 把 96×96 ARGB 图导出为 `main/desktop/assets/img_app_foo.c`，符号名 `img_app_foo`（与文件名一致）。

**4. 在 `desktop_data.c` 注册**：

```c
LV_IMAGE_DECLARE(img_app_foo);
// 在 desktop_apps[] 数组里加一行：
{ &img_app_foo, "Foo", 1, foo_app_launch },
// 并 #include "foo_app.h"
```

页码选择：page=1 主屏（前 10 个），page=2 次屏；超出 10 个会被跳过，要么砍掉占位项要么挪到 page=2。

**5. 字体子集补字**：如果 `name` 里有 SimSun 现有子集不包含的字符，把它们加到 SimSun 字体生成命令的字符集里，重生 `assets/fonts/desktop_font_simsun_*.c`。Phosphor 子集只服务状态栏/控制中心，不用动。

**6. CMake**：`CMakeLists.txt` 第 83~86 行已经 `file(GLOB)` 收 `main/desktop/*.c` 和 `assets/*.c`——新加的 `foo_app.c` 和 `img_app_foo.c` 自动被纳入；如果想被测试 target 看到，可仿照 252-264 行显式追加。

**7. 跑一次**：

```
cmake --build build && ./build/lvglsim                       # 默认 800x480
AM_RES=480x272 ./build/lvglsim                               # 切档冒烟
AM_PAGE=1 AM_SHOT=foo.png ./build/lvglsim                    # 单帧截图核对
AM_APP=foo ./build/lvglsim                                   # 直接进 foo（main.c 里加一个分支）
```

排错：

- 按下图标无反应：检查 `launch` 是不是 NULL、有没有进入 `did_drag=1` 分支（手指晃了 > 8px 算拖）。
- overlay 出来但内容黑屏：`builder` 没在 overlay 上挂任何子对象，或者 `foo_create` 写错 parent。
- 关闭后再打开崩：`foo_app_close` 没把 `lv_timer` / `lv_anim` 干掉，LVGL 还在回调已删除对象。
- 切回桌面后图标位置错乱：`desktop_run()` 复位静态数组的逻辑只在桌面重建时跑；app overlay 是叠加，不影响 icons[][]。

## 15. 分辨率自适应是怎么落地的

入口：`AM_RES=…` 或 `lv_sdl_window_create(w,h)` 之前的 `desktop_set_resolution(w,h)`。之后**所有像素值都不能硬编码**，统一从 `desktop_metrics()` / `desktop_grid_col_w()` / `desktop_grid_row_h()` 取。

具体落点：

- 壁纸：`wallpaper_for(m)` 按 `m->screen_w` 三选一。
- 状态栏：root 是 `screen_w × top_bar_h`；左槽 30%、右槽 45%；字体 `m->font_clock / font_glyph` 已按档预选。
- 桌面 home：`host` 占 `screen_w × (screen_h - top_bar_h)`。
- app 瓷砖：`col_w = screen_w / 5`、`row_h = (screen_h - top_bar_h - pager_h) / 2`。
- 图标缩放：C 数组按 96px 出图，800/640 档保持原比例（800 是 96，640 用 88 视觉略缩），480 档 60px。`lv_image_set_scale(img, 256 * icon_size / 96)`。
- 面板把手药丸：272 档下 40×4 px，否则 60×6 px（`desktop_widget_panel_handle`）。
- 锁屏大时钟：`m->font_big_clock`（Montserrat 48 / 40）。
- 面板：当前实现把 `h_control = h_notify = screen_h`，全屏铺满；metrics 里的 `panel_h=408/231` 字段保留给未来"非全屏"模式。

加新档：
1. `desktop_metrics.c::s_metrics[]` 新增条目。
2. `desktop_set_resolution()` 加分支。
3. 生成对应壁纸 C 数组（同档别名 `img_wallpaper_WxH`），`wallpaper_for()` 加分支。
4. 字体若按档分尺寸，准备对应 size 的子集字体并在 metrics 里指向。

## 16. 性能 / 注意事项

从源码里能直接看到的实践：

- **绝不在每帧 lv_obj_create**：桌面所有控件都在 `desktop_run()` 一次创建；后续只用 `lv_obj_set_pos / lv_image_set_scale / lv_label_set_text / lv_obj_move_foreground` 等"复用现有对象"的 API。状态栏更新走 `lv_timer + lv_label_set_text`，分页点更新走 `lv_obj_set_width + set_style_bg_opa`。
- **单 timer 单刷新**：状态栏只挂 1 个 `lv_timer`，且首次 period 对齐到下一整分钟，之后 60 s 长跑——一分钟一次重绘，开销可忽略。
- **图标缩放靠 set_scale，不预生成多档 C 数组**：换档时图标维持同一份内存，缩放在 GPU/blit 阶段做。代价：480 档下图标会被缩到 60/96=62.5%，质量略损但 RAM 不翻倍。
- **壁纸 `move_background` + tileview 透明**：壁纸是单张大图，常驻最底层；page 与 tileview 都开 `LV_OPA_TRANSP`，桌面切页不会触发壁纸重绘。
- **装饰对象批量 decorative**：`desktop_make_decorative()` 清掉 `CLICKABLE | SCROLLABLE`，避免命中测试遍历多余分支；也确保 panel 内任何空白处都能把按压"穿透"到面板自身，由 `attach_drag` 统一处理收起。
- **app overlay 用进程级单例**：`desktop_app_launcher` 防止重复打开，并显式恢复 screen 的 scrollbar 配置。app 内部如果有定时器/解码线程必须在 `close_cb` 里释放，否则 `lv_obj_delete(overlay)` 后回调悬空。
- **跨页拖拽用越界帧计数**：`touching_cb` 里 `border_lefttest_count > 70` 才切页——按 5 ms 一帧约 350 ms，避免手指轻微越界就翻页。
- **图标重排 user_data 跟着走**：`meta->app_idx` 存全局索引而非槽位坐标，搬家后 `released_cb` 直接拿出来 `launch()`，不用反查页/槽。
- **边缘条放最后建 = 渲染最顶**：靠 LVGL "子节点后绘"特性保证桌面态感应灵；面板展开后再 `move_foreground` 把面板压到感应条之上，避免在展开态又误触发边缘条。

潜在坑：

- `lv_screen_active()` 在多 display 场景会有歧义，本工程是单显示器、单 group，目前不会踩到。
- `top_bar_minute_timer_cb` 用 `time()`/`localtime_r()`，FreeRTOS 端要确认 RTC 已就位，否则时钟一直停在 `--:--`。
- `desktop_run()` 可重入，但若 app overlay 还开着调用它会留下悬空 overlay（`desktop_app_launcher_close` 未被调用过），调用方需先关 app。
- 12 项 app 全塞 page=1 会因 `DESKTOP_SLOT_COUNT=10` 丢掉最后两项——务必把溢出的搬去 page=2。
