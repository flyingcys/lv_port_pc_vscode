# v9_2048 LVGL 应用学习文档

一句话简介：经典 2048 滑块游戏的 LVGL 实现，纯逻辑层（core）与 UI 层完全解耦，支持 4×4 / 5×5 / 6×6 三种棋盘、键盘和手势输入、移动/合并/生成动画。

截图位：![v9_2048 主界面](./images/v9_2048-main.png)

## 1. 文件分层

| 文件 | 角色 | 关键内容 |
|------|------|----------|
| `main/src/v9_2048/game_2048_core.c` / `.h` | 纯逻辑层 | 棋盘数组、移动合并、随机生成、胜负判定。**不依赖 LVGL**，可单元测试。一句话算法：将每行/列向目标方向压缩后两两合并、再压缩，记录移动步骤供 UI 重放。 |
| `main/src/v9_2048/game_2048.c` / `.h` | LVGL UI 层 | 创建对象、绑定事件、播放动画、调用 core 接口。全局唯一实例 `s_ui`。 |
| `main/desktop/game_2048_app.c` | 桌面启动器适配 | `game_2048_app_launch()` 注册到 desktop launcher，挂载返回按钮。 |

## 2. 启动到首帧的 LVGL 调用链

```
game_2048_app_launch()                  // desktop/game_2048_app.c
 └─ desktop_app_launcher_open_with_close(game_2048_builder, ...)
     └─ game_2048_builder(overlay, w, h)
         ├─ game_2048_create(overlay, w, h)        // game_2048.c
         │   ├─ memset(&s_ui)
         │   ├─ create_layout()
         │   │   ├─ lv_obj_create(parent)          // root 容器
         │   │   ├─ create_header()                // 标题 + SCORE/BEST
         │   │   ├─ create_controls()              // 4x4/5x5/6x6 + New Game
         │   │   ├─ create_board()                 // 棋盘容器 + 事件回调
         │   │   └─ lv_group_add_obj(group, board) // 键盘焦点
         │   └─ reset_game()
         │       ├─ game_2048_core_init()
         │       ├─ reset_board_children()         // 算 gap/tile_size/radius
         │       ├─ create_background_tiles()      // N×N 灰底格
         │       └─ rebuild_tiles()                // 当前数字 tile
         ├─ create_back_button(overlay)
         └─ game_2048_start()                      // 再 reset 一次
```

## 3. UI 组成与控件选型

| 区域 | LVGL 控件 | 要点 |
|------|-----------|------|
| Root 容器 | `lv_obj_create` + `lv_obj_remove_style_all` | 全屏纯色背景 `0xFAF8EF` |
| 标题 "2048" | `lv_label_create` + `lv_font_montserrat_48` | 固定左上 |
| SCORE / BEST 框 | `lv_obj_create`（盒）+ 内嵌两个 `lv_label` | 盒底色 `0xBBADA0`，圆角 8 |
| 尺寸切换按钮（4x4/5x5/6x6） | `lv_button_create` × 3，外层 flex `lv_obj` | 通过 `lv_obj_set_user_data` 把 size 存进按钮 |
| New Game | `lv_button_create` | 暖棕色 `0x8F7A66` |
| 棋盘 | `lv_obj_create` 一个盒 | 监听 `LV_EVENT_PRESSED/RELEASED/KEY` |
| 棋盘背景格 | N×N 个 `lv_obj_create`，灰色 `0xCDC1B4` | 仅作背景占位 |
| 数字 cell | **`lv_obj`（带样式）+ 居中 `lv_label` 子对象** | 不是单一 label；详见下节 |
| 状态文字（Game Over / win） | `lv_label` 对齐棋盘下方 | **无独立弹窗**，用 status_label 直接刷文字 |

注意：本实现 **没有 modal Game Over 弹窗**，只在 `status_label` 上刷 "Game over" / "You win. Keep going."。

## 4. 数字 cell 的结构与颜色映射

每个 cell 是 **`lv_obj` 容器 + 居中 `lv_label`**：
- 容器负责 `bg_color`、`radius`、移动/缩放动画。
- 子 label 负责数字文本、`text_color`、字体大小。

颜色采用 **静态查表数组** `k_tile_styles[]`（`game_2048.c` 第 47-54 行），每项 `{value, bg, fg}`，覆盖 2…2048。查表逻辑在 `apply_tile_style()`：线性扫描数组，命中则取色，超出 2048 用兜底深色 `0x3C3A32`。

字体也按数字大小分级，`tile_font()` 根据 `ui->tile_size` 和数值挑 `montserrat_16/20/24/32/40` 三档，避免大数字溢出 cell。

## 5. 动画：用了 `lv_anim`

三类动画均以 `lv_anim_t` 实现，时长常量：移动 140 ms，淡出 90 ms，弹出 130 ms。

| 动画 | 函数 | 关键 API |
|------|------|----------|
| 平移（每一步 move） | `animate_tile_move()` | 双 anim：`anim_x_cb`/`anim_y_cb` → `lv_obj_set_x/y`；`lv_anim_path_ease_out` |
| 消失（合并掉的源 tile） | `animate_tile_move(disappear=true)` + `anim_disappear_ready_cb` 链式起淡出 | `anim_opa_cb` → `lv_obj_set_style_opa`，结束回调中 `lv_obj_delete` |
| 新 tile 弹出 | `animate_tile_spawn()` | 透明度 0→COVER + `transform_width/height` 12→0 |
| 合并放大 | `animate_tile_merge()` | `transform_width/height` 0→14，`lv_anim_set_playback_time(90)` 自动回弹 |

收尾回调 `anim_transform_reset_cb` 复位 transform；若 opa 为 0 则直接 `lv_obj_delete`。

## 6. 输入 → core → 重绘

三种输入统一收敛到 `move_by_dir(dir)`：

| 输入 | 入口 | 处理 |
|------|------|------|
| 键盘方向键 | `event_key_cb`（`LV_EVENT_KEY`） | `lv_event_get_key()` 判断 `LV_KEY_LEFT/RIGHT/UP/DOWN` |
| 手势滑动 | `event_board_cb`（`LV_EVENT_PRESSED` + `RELEASED`） | `lv_indev_get_point()` 记录起止点；阈值 = `tile_size/4`（最小 16）；按 \|dx\| 与 \|dy\| 大小判方向 |
| 按钮 | `event_reset_cb` / `event_size_cb` | `LV_EVENT_CLICKED` → 直接 `reset_game()` |

`move_by_dir` 三步：
1. `game_2048_core_move(&game, dir, &result)`：core 算出步骤数组 `result->steps[]` + 是否新增 tile。
2. `apply_move_steps()`：先扫所有 step 发 `animate_tile_move`，把幸存 tile 写回新坐标的 `ui->tiles[r][c]` 并刷样式；若 `merged` 再叠合并动画；最后用 `create_tile` + `animate_tile_spawn` 加新 tile。
3. `update_score()` / `update_status()` 刷文本。

防重入：`ui->animating` 标志位拦截动画中的二次输入。

## 7. 分辨率自适应（800×480 / 640×480 / 480×272）

布局尺寸来自 `desktop_metrics()` 传入的 `screen_w / screen_h`，关键自适应点：

- **header 边距**：`margin = screen_w < 520 ? 24 : 48`（窄屏靠边）。
- **棋盘尺寸**：`board_size = min(screen_w-72, screen_h-190)`，再 clamp 到 `[240, 520]`。所以 480×272 屏取 `272-190=82`...实测会被 clamp 到 240，需要小屏屏注意 header 重叠。
- **gap / tile_size / radius**：在 `reset_board_children()` 中按 `board_size` 与 `grid_size` 动态算：`gap = board_size/(grid*10)` clamp `[6,14]`，`tile_size = (board - gap*(grid+1))/grid`，`radius = tile_size/12` 最小 4。
- **字体分级**：`tile_font()` 用 `tile_size >= 90 / 66` 两道阈值切换字号，保证小屏数字仍能塞进 cell。

## 8. 关键 API 速查

- 容器/控件：`lv_obj_create`、`lv_button_create`、`lv_label_create`、`lv_obj_remove_style_all`
- 样式：`lv_obj_set_style_bg_color/bg_opa/radius/border_width/text_color/text_font/opa/transform_width/transform_height`
- 布局：`lv_obj_set_size/pos`、`lv_obj_align`、`lv_obj_set_flex_flow`、`lv_obj_set_flex_align`
- 事件：`lv_obj_add_event_cb`、`lv_event_get_code/key/indev/user_data/target`、`lv_indev_get_point`
- 焦点：`lv_group_get_default`、`lv_group_add_obj`、`lv_group_focus_obj`
- 动画：`lv_anim_init/set_var/set_exec_cb/set_values/set_time/set_path_cb/set_ready_cb/set_playback_time/start`
- 生命周期：`lv_obj_clean`、`lv_obj_delete`、`lv_obj_get_child`、`lv_tick_get`
