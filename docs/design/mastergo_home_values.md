## 布局策略

- 页面是固定尺寸 `480x480`，后续 LVGL 应按绝对坐标还原。
- 首页核心结构由以下几部分组成：
  - 背景地球图层
  - 左上大时钟区
  - 右上天气/温度区
  - 日期/星期区
  - Wi-Fi 图标区
  - 两张开关卡片
  - 底部分页指示器
- 页面主结构不建议改成整页 `flex/grid`，只允许在局部重复单元中使用容器。

## 坐标口径说明

- 本文表格中的 `x/y/w/h` 默认以页面根节点左上角为参考系。
- 如果某一行记录的是 DSL 子节点的局部坐标，而不是页面绝对坐标，会在“资源/备注”列中显式标注“相对某父容器”。
- 后续 LVGL 实现时，允许通过局部容器组织代码，但最终落点必须与这里记录的页面绝对几何结果一致。

## interactive 检查结果

- 本页当前 DSL 输出中未发现 `interactive` 导航元数据。
- 因此首页到场景页的左右滑动、顶部下拉打开设置、语音弹窗显示，都应视为后续在 LVGL 中手工实现的交互，而不是 DSL 原生导航关系。

## LVGL 难以 1:1 还原的效果分类

- 原生 LVGL 可实现：
  - 大部分文本、圆角矩形、分页指示器
  - Wi-Fi 图标路径
  - 天气图标中的部分矢量结构
- 建议本地光栅资源：
  - 地球背景图
- 可能存在受控偏差：
  - 深色开关卡片的玻璃质感和半透明叠色
  - 天气图标复杂矢量细节

## 必须严格对齐项

- 页面尺寸必须是 `480x480`
- 大时钟区、天气区、日期区、Wi-Fi 区和两张开关卡片的坐标关系不能改
- 两张开关卡片的深浅主题不能交换
- `Switch 1` / `Switch 2` 文本区域位置与字体风格要保持一致
- 底部分页指示器必须保持首页第一页激活态

- 已精确对齐项：

  - 天气图标与 Wi-Fi 细节暂用 LVGL 文本/符号占位，而不是严格复刻 MasterGo 的矢量路径细节。
