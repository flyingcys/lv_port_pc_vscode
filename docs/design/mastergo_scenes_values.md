## 场景槽位与需求关系

- 当前页 DSL 已冻结的标准场景卡片尺寸为 `219 x 135`，页面采用卡片式场景展示。
- 需求文档要求“最多支持 8 个场景”。
- 因此实现时数据模型必须预留 8 个场景，不应被当前单屏可见卡片数量限制。
- 具体是分页、滚动还是固定可见子集，属于后续实现策略选择；不影响当前 Task 1 已冻结的页面几何和标准场景卡片模板。
