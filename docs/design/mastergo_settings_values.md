## 页面信息

## 布局策略

- 设置页不是标准 `480x480` 画板，而是 `480x656`，说明设计上更接近“从顶部拉下展开的长面板”。
- 顶部仍保留天气/时钟/Wi-Fi 区和页标题。
- 主要内容区是一个 `448 x 467` 的纵向设置容器，内部由多个 `448` 宽的玻璃感卡片组成：
  - 亮度调节块
  - 自动熄屏块
  - 接近亮屏块
  - 关于块
- 底部存在渐变遮罩和 3 段分页指示器。

## 坐标口径说明

- 本文表格中的 `x/y/w/h` 默认以页面根节点左上角为参考系。
- 如果某一行记录的是 DSL 子节点的局部坐标，而不是页面绝对坐标，会在“资源/备注”列中显式标注“相对某父容器”。
- 设置页后续可通过局部容器承载卡片内容，但最终显示结果必须对齐这里记录的页面级几何关系。

## 设计示例态与实现默认值

- 本页 DSL 反映的是某一次设计展示状态，不等同于软件功能默认值。
- 表格中的亮度文案 `50%` 只表示设计示例态；需求文档规定亮度初始值应为 `100%`。
- 表格中的自动熄屏文案 `15s` 只表示设计示例态；需求文档规定默认值应为 `5 分钟`。
- 因此后续实现时，应优先服从 `docs/requirements/ai_voice_screen_switch_lvgl_requirements.md` 中的软件默认值定义。

## interactive 检查结果

- 本页当前 DSL 输出中未发现 `interactive` 导航元数据。
- 设置页的“下拉进入”和“右箭头进入二级内容”在 DSL 中表现为视觉结构，不应直接视为 MasterGo 自动导航关系。
- “关于”是否一定进入独立二级页，需要以后续产品定义或原型交互确认为准。

## LVGL 难以 1:1 还原的效果分类

- 原生 LVGL 可实现：
  - 标题文本、状态文本、箭头图标、开关圆点
  - 亮度进度条、分页指示器
  - 多数设置项图标
- 建议本地光栅资源：
  - 如果后续发现局部图标路径组合过于复杂，可将单个图标导出为本地资源
- 可能存在受控偏差：
  - 毛玻璃模糊效果
  - 接近亮屏开关的微模糊和高光细节

## 必须严格对齐项

- 设置页应按 `480x656` 的长面板思路实现，不要直接裁成 `480x480`
- 内容主容器必须保持 `448 x 467`，并且位于 `x=16, y=134`
- 亮度、自动熄屏、接近亮屏、关于四个区块的纵向顺序不能改变
- 亮度滑条的整体宽度 `408`、已选区宽度 `247`、百分比示例文案 `50%` 的设计位置必须对齐，但运行时默认值仍应服从需求文档
- 分页指示器必须保留 3 段结构，并按设置页第 3 页激活态处理
