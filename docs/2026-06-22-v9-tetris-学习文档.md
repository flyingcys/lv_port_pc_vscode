# v9-tetris 学习文档

> LVGL v9 实现的桌面俄罗斯方块小游戏。游戏算法（碰撞 / 旋转 / 消行）放在 `tetris_game.c`，本文不展开，专注 UI 层。

## 1. 文件分层

| 文件 | 职责（一行说明） |
|------|------------------|
| `main/desktop/tetris_app.c` | 桌面启动器入口，调 `tetris_create` + 叠加返回按钮 |
| `main/src/v9-tetris/tetris.c` | 应用门面：组装 game/ui/input + `lv_timer` 主循环 |
| `main/src/v9-tetris/tetris_game.c` | 纯逻辑：棋盘数组、方块状态机、消行、计分 |
| `main/src/v9-tetris/tetris_ui.c` | LVGL 视图层：容器、Canvas、Label、Button、MsgBox |
| `main/src/v9-tetris/tetris_input.c` | 键盘输入：`LV_EVENT_KEY` + `lv_group` 焦点接管 |

## 2. 启动到首帧的 LVGL 调用链

```
desktop_app_launcher_open_with_close()
  └─ tetris_builder()                         // tetris_app.c
       ├─ tetris_create(overlay, w, h)        // tetris.c
       │    ├─ lv_obj_create(parent)          // 根容器
       │    ├─ lv_obj_remove_style_all()
       │    ├─ lv_obj_set_size(w, h)
       │    ├─ tetris_game_init()
       │    ├─ tetris_ui_init()               // 见 §3
       │    ├─ tetris_input_init()            // 注册键盘事件
       │    └─ lv_timer_create(tick_cb,50ms)  // 主循环 paused
       ├─ create_back_button(overlay)         // 返回按钮叠加
       └─ tetris_start()
            ├─ tetris_game_start()
            ├─ tetris_ui_update()             // 首帧
            └─ lv_timer_resume()
```

关键点：根 `lv_obj` 用 `lv_obj_remove_style_all` 去掉默认边框，全屏铺满；定时器先创建后 pause，避免初始化途中触发回调。

## 3. UI 组成与所用控件

主容器走 Flex 行布局，左侧棋盘 + 右侧侧栏。

| 区域 | 控件 | 关键 API |
|------|------|----------|
| 主容器 | `lv_obj` (Flex Row) | `lv_obj_set_flex_flow(LV_FLEX_FLOW_ROW)` + `lv_obj_set_flex_align(CENTER,CENTER,CENTER)` |
| 主棋盘 | **`lv_canvas`** (单个) | `lv_canvas_create` + `lv_draw_buf_create(200×400, RGB565)` + `lv_canvas_set_draw_buf` |
| 侧栏容器 | `lv_obj` (Flex Column) | `lv_obj_set_flex_flow(LV_FLEX_FLOW_COLUMN)` |
| SCORE/LINES/LEVEL | `lv_label` × 6 (标题 + 数值) | `lv_label_set_text` + `lv_obj_set_style_text_font(montserrat_20/24)` |
| 下一个方块预览 | **`lv_canvas`** (4×4 cell) | 同上，`lv_draw_buf` 尺寸 80×80 |
| START / PAUSE / RESET | `lv_button` × 3 + 内嵌 `lv_label` | `lv_obj_add_event_cb(..., LV_EVENT_CLICKED, ui)` |
| Game Over | `lv_msgbox` (按需创建) | `lv_msgbox_create` + `lv_msgbox_add_title/text/footer_button` |
| 返回按钮 | `lv_button`（圆形）+ `lv_label`(LV_SYMBOL_LEFT) | `tetris_app.c` 里 overlay 层 |

注意：**没有用 lv_btnmatrix**，按钮是三个独立 `lv_button`；状态切换通过 `LV_OBJ_FLAG_HIDDEN` 的增删实现（idle 显示 START，playing 显示 PAUSE）。

## 4. 棋盘格渲染（核心）

**结论：不用 10×20 个 lv_obj，整张棋盘是一个 `lv_canvas`，每帧整体重绘。**

棋盘 = 1 个 `lv_canvas` + 1 个 `lv_draw_buf`（200 px × 400 px，RGB565，约 156 KB）。

每次 `tetris_ui_update` → `draw_game_board`：

1. `lv_canvas_fill_bg(canvas, 0x000000, LV_OPA_COVER)` 清屏。
2. 遍历 `game->board[20][10]`，非空格调用 `draw_cell` 写入 draw_buf。
3. 叠加当前下落中方块（同样调 `draw_cell`）。
4. `lv_canvas_init_layer` 取出 layer，用 `lv_draw_rect_dsc` + `lv_draw_rect` 画 11+21 条网格线，`lv_canvas_finish_layer` 提交。

`draw_cell` 实现走了**直接写 buffer 像素**这条路（性能优先）：

```
uint16_t *buf_data = (uint16_t *)draw_buf->data;
uint32_t stride = lv_draw_buf_width_to_stride(w, RGB565);
buf_data[py * stride/2 + px] = lv_color_to_u16(color);
```

外形支持 3 种风格（`tetris_block_style_t`）：SOLID 实心 / INSET 缩 4 px / OUTLINE 仅边框 3 px。按 `S` 键循环切换。

`CELL_SIZE = 20` 写死在 `tetris_ui.h`，棋盘画布尺寸 `BOARD_WIDTH(10)*20 = 200`、`BOARD_HEIGHT(20)*20 = 400`。

## 5. 帧更新机制

- 主循环：`lv_timer_create(tetris_tick_cb, 50 ms, NULL)`，对应 20 FPS。
- 回调里调 `tetris_game_update(tick)` 推进逻辑 + `tetris_ui_update()` 重绘。
- 输入事件触发后**立即同步**调一次 `tetris_ui_update()`，不等下一帧（响应感）。
- 没有用 `lv_anim`，所有移动以 cell 为单位整格瞬移。
- 暂停 = `lv_timer_pause(s_timer)`；停止 = `lv_timer_delete` + `lv_obj_delete(root)` + `lv_draw_buf_destroy`。

## 6. 输入接入 LVGL

走的是 **`lv_obj` event + `lv_group`** 路线，不是自定义 `lv_indev`。

`tetris_input_init(game, ui, target)` 做了 4 件事：

1. `lv_obj_add_event_cb(target, cb, LV_EVENT_KEY, NULL)`
2. `lv_obj_add_event_cb(target, cb, LV_EVENT_RELEASED, NULL)`
3. 给 target 加 `LV_OBJ_FLAG_CLICKABLE | LV_OBJ_FLAG_CLICK_FOCUSABLE`
4. `focus_keyboard_target`：取默认 group → `lv_group_add_obj` → `lv_group_focus_obj` → 遍历 `lv_indev_get_next`，找到 `LV_INDEV_TYPE_KEYPAD` 用 `lv_indev_set_group(kb, group)` 绑死。

按键映射（`lv_event_get_key`）：

| 键 | 动作 |
|----|------|
| `LV_KEY_LEFT/RIGHT` | 左右移动（带 150 ms 首延 + 50 ms repeat） |
| `LV_KEY_UP` | 旋转（不允许 repeat） |
| `LV_KEY_DOWN` | 软降（按住期间持续） |
| Space | 暂停切换 |
| S | 切换 cell 风格 |

防抖在用户态自己做（`s_key_pressed[256]` + `s_last_key_time[256]` + `lv_tick_get()`），没依赖 LVGL 的 long-press 机制。

触摸：仅 START/PAUSE/RESET 三个按钮可触摸，棋盘本身**没有触摸手势**。

## 7. 分辨率自适应

入口：`desktop_metrics()` 给出 `screen_w / screen_h`，沿 `tetris_app.c → tetris.c → tetris_ui.c` 一路透传。

实际策略：

- 根 `lv_obj` 与主容器 `lv_obj_set_size(screen_w, screen_h)` 全屏铺满。
- 主容器用 Flex `CENTER/CENTER/CENTER` 让 "棋盘 + 侧栏" 整体居中，多出的空白自然落到四周。
- 棋盘尺寸**固定** = `10 × 20 × 20 = 200×400`，侧栏宽固定 150。
  - 800×480：左右各留约 215 px 空白，舒展。
  - 640×480：左右各留约 135 px 空白，可用。
  - 480×272：棋盘高 400 > 屏高 272 —— 会被 Flex 居中但**超出底边裁掉**，此分辨率下需要降低 `CELL_SIZE` 或改棋盘行数才能完全显示（当前实现未处理）。

> 建议改进：把 `CELL_SIZE` 从宏改成 `screen_h / 24` 之类的动态值，drawbuf 跟着算。

## 9. 一句话总结

UI = 一张 Canvas 直绘棋盘 + 一张 Canvas 直绘 Next + 若干 Label/Button；50 ms `lv_timer` 推帧；键盘走 `lv_obj` 事件 + `lv_group` 接管 keypad indev；分辨率靠 Flex 居中，但 cell 尺寸写死，480×272 下棋盘会溢出。
