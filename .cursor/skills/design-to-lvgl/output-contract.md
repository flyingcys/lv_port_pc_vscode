# 输出契约

本文件只定义输出格式，避免把模板散落在主 skill 或来源文档里。

## 实现前摘要模板

开始实现前，先给出：

```markdown
## 实现前摘要
- 设计源：
- 目标节点：
- 页面尺寸：
- 当前范围：
- 布局策略：
- 命名方案：
- 页面结构摘要：
- 必须严格对齐的设计值：
- 关键设计值对照表：
- 计划修改或新增文件：
- 本地化资源方案：
- 字体接入方案：
```

## 关键设计值对照表模板

实现前必须先整理成表，再开始写代码。最少字段如下：

```markdown
## 关键设计值对照表

| 模块 | 节点/元素 | x | y | w | h | radius | font | size | weight | line-height | letter-spacing | color | opacity | shadow | 对齐 | 资源/备注 |
|------|-----------|---|---|---|---|--------|------|------|--------|-------------|----------------|-------|---------|--------|------|-----------|
| 页面背景 | background | 0 | 0 | 480 | 480 | 0 | - | - | - | - | - | #000000 | 1 | none | lt | 背景图/纯色 |
| 顶部天气区 | weather-block | 24 | 32 | 120 | 48 | 0 | Urbanist | 16 | 700 | 19 | 0 | #FFFFFF | 1 | none | lt | 示例行 |
```

约束：

- 表中的值必须来自设计数据，不允许凭经验补数字
- 设计值缺失时，要明确标记“设计未提供”
- 如果实现中调整了某个值，必须回到表里同步更新，并说明原因
- 最终汇报时，要基于这张表说明哪些项已对齐，哪些项仍有偏差
