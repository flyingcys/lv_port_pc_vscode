# 横屏电子时钟复刻设计

## 1. 目标

基于素材 `1.jpg` 和 `IMG_4025.mp4`，实现一个横屏 `800x480` 的网页时钟界面。

目标结果：

- 视觉风格接近照片中的电子屏界面
- 时间为真实系统时间，不是固定视频脚本循环
- 动画语言参考视频：数字更新时整体向上滚动
- 页面适合作为独立静态网页直接打开运行

## 2. 输入真相

本次设计基于以下已确认约束：

- 成品画布固定为 `800x480`
- 视频仅作为动画节奏和滚动方向参考
- 最终网页为横屏，不按视频竖屏布局复刻
- 时间使用本机系统时间实时更新
- 小时、分钟、秒钟都需要在数值变化时执行上移滚动
- 温度和湿度先使用示例值固定展示
- 不模拟真实拍摄造成的透视、摩尔纹、反光、噪点

## 3. 结果形态

采用静态网页多文件结构：

- `index.html`
- `styles.css`
- `script.js`

这样做的原因：

- 结构、样式、行为分离，方便后续微调视觉和动画
- 比单文件更适合继续迭代
- 仍然足够轻量，可直接本地打开使用

## 4. 布局设计

整体分为三段：

1. 顶部日期栏
2. 中部主时钟区
3. 底部状态栏

### 4.1 顶部日期栏

顶部栏高度约占整体的 `16%`，采用亮青色渐变背景。

内容：

- 左侧显示年份，例如 `2024`
- 中间显示月份英文大写，例如 `DECEMBER`
- 右侧显示日期，例如 `30`

布局原则：

- 左中右三段对齐
- 中间月份最大，形成视觉中心
- 字体风格偏衬线、粗体、带轻微复古电子看板感

### 4.2 中部主时钟区

中部区域高度约占整体的 `68%`，背景为白到浅蓝的轻渐变。

内容：

- 顶部小标题显示时段文案，例如 `EVENING`
- 中央大号时间，格式为 `HH:MM:SS`
- 秒钟右上附近悬浮一个小闹钟图标作为装饰

时间数字规则：

- 共 6 个数字位：`H1 H2 M1 M2 S1 S2`
- 两个冒号位于小时、分钟之间
- 数字位尺寸统一，居中排列
- 数字颜色为偏红橙色，高饱和
- 数字主体需要占据页面主要视觉面积

### 4.3 底部状态栏

底栏高度约占整体的 `16%`，使用蓝色渐变背景。

内容：

- 左侧显示温度，例如 `25.6 °C`
- 中间显示星期英文大写，例如 `MONDAY`
- 右侧显示湿度，例如 `65 %`

布局原则：

- 中间星期最稳，形成底部中心锚点
- 左右信息较轻，但仍保留图中信息屏感觉

## 5. 数据与文案映射

### 5.1 时间

从浏览器环境读取本机系统时间。

更新时间规则：

- 页面加载时立即渲染一次当前时间
- 后续按“下一秒边界”调度更新
- 不使用固定 `setInterval(1000)` 直接累加，避免长时间运行后漂移

### 5.2 日期

日期栏内容来自系统日期：

- 年：数字
- 月：英文大写月份名
- 日：数字

### 5.3 星期

底栏中部星期来自系统星期，显示英文大写：

- `SUNDAY`
- `MONDAY`
- `TUESDAY`
- `WEDNESDAY`
- `THURSDAY`
- `FRIDAY`
- `SATURDAY`

### 5.4 时段文案

中部标题文案根据小时切换，默认使用以下映射：

- `05:00-11:59` -> `MORNING`
- `12:00-16:59` -> `AFTERNOON`
- `17:00-22:59` -> `EVENING`
- 其他时间 -> `NIGHT`

该映射主要用于增强成品图中的“状态词”观感，不追求复杂本地化。

### 5.5 温度与湿度

第一版固定展示：

- 温度：`25.6`
- 湿度：`65`

后续若需要，可扩展为真实接口或外部输入，但不属于本次实现范围。

## 6. 动画设计

### 6.1 动画原则

动画核心目标不是做通用网页数字切换，而是模拟视频中电子屏数字更新时“向上推卷”的感觉。

统一规则：

- 只有发生变化的数字位才执行滚动
- 滚动方向固定为向上
- 当前数字上移并淡出
- 下一数字从底部进入并停稳

## 6.2 各时间位行为

### 秒钟

- 每秒至少有一个数字位发生变化
- 秒个位几乎每秒滚动
- 秒十位在 `09 -> 10`、`19 -> 20` 等时刻滚动

### 分钟

- 在秒钟归零、分钟变化时触发
- 分个位和分十位按真实进位规则各自滚动

### 小时

- 在分钟和秒钟同时归零且小时变化时触发
- 小时十位和个位按实际变化情况滚动

## 6.3 冒号

冒号不做滚动。

固定行为：

- 保持常亮
- 叠加非常轻微的呼吸或亮度波动

目的：

- 让页面有电子屏活性
- 但不与主数字滚动抢焦点

### 6.4 动画节奏

单次数字滚动时长固定控制在 `260ms-320ms`。

节奏要求：

- 前段启动较快
- 后段减速落稳

使用带轻微冲感、但不过度弹跳的缓动曲线，保证看起来像屏幕刷新，而不是卡片翻页。

## 7. 实现结构

### 7.1 `index.html`

负责：

- 页面骨架
- 顶部、中部、底部三段结构
- 六个数字位容器
- 冒号、时段文案、装饰图标、底栏信息节点

采用语义清晰的块级结构，例如：

- `screen`
- `screen__header`
- `screen__clock`
- `digit-slot`
- `screen__footer`

### 7.2 `styles.css`

负责：

- 画布尺寸与居中展示
- 颜色系统与渐变背景
- 字体层级与字重
- 时间区布局
- 数字槽样式
- 上移滚动动画
- 冒号轻呼吸动画

样式目标：

- 接近电子信息屏，不做现代卡片 UI
- 避免通用网页组件感
- 让数字成为绝对主视觉

### 7.3 `script.js`

负责：

- 获取系统时间
- 生成日期、星期、时段文案
- 构建统一 view model
- 维护 6 个数字位的当前值
- 比较新旧值，决定哪些位需要滚动
- 在秒边界对齐刷新
- 更新温度、湿度静态文案
- 在 DOM 完整时启动页面时钟

脚本按以下结构组织：

- `buildViewModel(date)`
- `getDelayToNextSecond(date)`
- `getTimeParts(date)`
- `getDayLabel(date)`
- `getMonthLabel(date)`
- `getPeriodLabel(hour)`
- `renderClock(dom, viewModel)`
- `animateDigit(slot, nextValue)`
- `startClock()`

其中 `startClock()` 会在 `DOMContentLoaded` 后执行，先收集并校验页面节点，再通过内部 `tick()` 立即渲染一次当前时间，并结合 `getDelayToNextSecond()` 用 `setTimeout` 对齐到下一秒边界持续刷新。

## 8. 验收标准

满足以下条件视为本次复刻达标：

### 8.1 视觉

- 画布固定为 `800x480`
- 顶部青色栏、中部白色舞台、底部蓝色栏结构明确
- 时间数字足够大，视觉风格接近参考图
- 颜色层次与参考图同类，不出现明显现代网页卡片感

### 8.2 行为

- 页面打开即可显示当前真实系统时间
- 秒钟稳定更新
- 分钟、小时进位正确
- 所有变化数字位均向上滚动
- 未变化数字位保持静止

### 8.3 稳定性

- 长时间运行不明显漂移
- 无控制台报错
- 本地直接打开可运行，不依赖构建系统

## 9. 非范围项

以下内容不纳入本次实现：

- 与拍摄设备一致的透视变形
- 真实屏幕边框、摩尔纹、反光、噪点模拟
- 外部天气 API
- 真实硬件传感器输入
- 完整视频逐帧复刻

## 10. 实施顺序

按以下顺序完成最小闭环：

1. 搭出 `800x480` 静态布局
2. 接入真实时间和日期
3. 让秒钟滚动跑通
4. 扩展到分钟、小时进位滚动
5. 最后微调字体、间距、颜色和弱呼吸动画

这个顺序可以先验证“像不像”，再处理细节，不会一开始就陷入纯视觉微调。
